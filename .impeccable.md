## Design Context

### Users
Players engaging with a terminal-native cyberpunk tactics game. They are here to build clever daemon combinations, read the state of combat clearly, and feel like they are operating inside a dangerous living network rather than a generic menu app.

### Brand Personality
Hacker, cyberpunk, philosophical/paradoxical. The interface should feel tense, intelligent, and slightly unstable, with enough clarity that the player always understands what happened.

### Aesthetic Direction
Text-first retro-futurist systems fiction with dangerous, glitchy energy. Motion should feel like hostile infrastructure reconfiguring itself, not playful UI polish. The interface should avoid anything cheap, lame, obvious, or predictable.

### Design Principles
1. Motion must clarify state change before it decorates it.
2. The terminal should feel alive and unstable, but never unreadable.
3. High-impact moments should feel earned, staged, and ritualistic.
4. Surprise should come from composition and timing, not random visual noise.
5. Every major interaction should feel like system intervention, not button clicking.
